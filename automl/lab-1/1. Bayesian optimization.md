# Лабораторная работа №1. Байесовская оптимизация

# Задание:

1. Выберите алгоритм обучения с учителем с большим числом гиперпараметров.
2. Выберите набор данных и целевую функцию оценки алгоритма.
3. Реализуйте алгоритм байесовской оптимизации и случайный поиск.
4. Сравните алгоритм байесовской оптимизации со случайным поиском.
5. Визуализируйте значение целевой функции в зависимости от номера шага.
6. Визуализируйте пространство протестированных значений гиперпараметров. Цветом обозначьте значение целевой функции на них. При необходимости сделайте проекцию в двухмерное пространство.
7. Оцените важность гиперпараметров при помощи любого метода выбора признаков.
8. Повторите шаги 4–7 при помощи библиотеки optuna.

# Примечание:

* Шаги 5–7 следует производить для алгоритма байесовской оптимизации и случайного поиска.
* Разрешается использовать любую функцию улучшения.  
* Разрешается использовать любую суррогатную функцию, которая способна оценивать неопределённость предсказания. Желательно использовать случайный лес или гауссовы процессы.
* Набор данных можно подобрать на [https://www.openml.org/search?type=data](https://www.openml.org/search?type=data)
