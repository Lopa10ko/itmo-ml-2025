# Лабораторная работа №3. Настройка архитектуры нейронной сети

# Задание:

1. Выберите любой набор данных для задачи обучения с учителем.
2. Выберите целевую метрику качества.
3. Разбейте набор данных на три части: обучающая, валидационная и контрольная выборки
4. Сведите задачу настройки архитектуры к оптимизации и решите её с помощью Optuna или аналогичного оптимизатора.
5. Воспользуйтесь специальной библиотекой для поиска архитектуры нейронной сети, например, Auto-PyTorch или аналогичной библиотекой.
6. Попросите любую LLM построить архитектуру по описанию набора данных и задачи. Сообщите ей качество работы на валидационной части набора данных и попросите модифицировать архитектуру. Сделайте несколько таких итераций (от 10).
7. Измерьте качество, скорость работы (время обучения и инференса) и число параметров полученных архитектур с 4–6 шагов на контрольной части набора данных. Постройте кривые обучения на одном графике.

# Примечание:

* Можно также использовать набор данных для распознавания изображений.
* Не стоит брать слишком большие наборы данных, чтобы настройка архитектуры занимала разумное время.
  Не стоит брать большие наборы данных, чтобы модель работала быстро на нём.
* На шагах 4–6 нельзя использовать контрольную часть набора данных для измерения качества работы при поиске архитектуры.
* На 7-м шаге требуется несколько раз измерять качество для каждой архитектуры с разными random seed, усреднять результаты и строить доверительный интервал.
